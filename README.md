# 💬 Let's Chat — Android Chat Application

An Android real-time chat application built with Java. This project demonstrates core Android concepts like socket-based or Firebase-backed messaging, activity navigation, and RecyclerView-driven chat UI.

## 📱 Features

- Real-time messaging interface
- Chat list and individual conversation screens
- Message send/receive UI

## 🛠️ Tech Stack

| Layer | Technology |
|---|---|
| Language | Java |
| Platform | Android |
| Build System | Gradle |
| IDE | Android Studio |

## 🚀 Getting Started

### Prerequisites
- Android Studio (any recent version)
- Android SDK (API 21+)
- Java 8+

### Run Locally

```bash
# Clone the repository
git clone https://github.com/aishwary08/Lets_Chat.git

# Open in Android Studio
# File → Open → select the cloned folder

# Sync Gradle and run on emulator or device
```
